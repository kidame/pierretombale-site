## Statut et limites

PNG originaux 1254 x 1254, sans agrandissement. La demande de 2048 px n'a pas ete livree par le moteur ; le minimum final de 1600 px n'est pas atteint. Export JPG final reporte.
Vue axiale legerement plongeante, pas une elevation orthographique stricte. Silhouette visuellement coherente mais contours non verifies au pixel. Dimensions et zone gravable en cm inconnues : aucune calibration garantie.
Stele nue, vase et fleurs retires. Materiaux synthetiques issus des references, sans calibration colorimetrique ou echelle physique du grain. Valider les nuances et veinages sur echantillons reels avant usage commercial.
Ce lot est un pilote a valider, pas un asset final de gravure. La seconde vue stele est reportee selon la demande utilisateur.
Aucune modification de granits.json ni publication runtime. Transferts verifies par SHA256.
