# CIN-AQUARIUS - pilote v1

Source : libfile_6d912d4257d48191ba48a95e0c5fbb59.
Dalle de base rectangulaire, socle arriere a deux niveaux. Stele asymetrique aux flancs galbes, sommet en vague descendant vers la droite; petit epaulement concave a gauche sous le point haut. Vase et bambou sont amovibles. Leurs reflets doivent aussi disparaitre. Aucun bicolore structurel identifie. Geometrie atelier et zones physiques a valider.

Une vue par matiere ; nom public et calibration non valides.
