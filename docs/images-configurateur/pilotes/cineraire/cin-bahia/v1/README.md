# CIN BAHIA - pilote v1

Source : libfile_cc288cda143481918fdb5cebd6cd857a.
Stele simple rectangulaire verticale, sur une longue marche arriere. Base rectangulaire a deux niveaux; grande dalle intermediaire legerement en retrait de la semelle. Bicolore confirme visuellement. Zone variable retenue : stele et dalle intermediaire gris-bleu d'origine. Semelle et marche arriere claires conservees comme seconde pierre fixe; choix pilote sans multiplier les combinaisons. Geometrie atelier et zones physiques a valider.

Une vue par matiere ; nom public et calibration non valides.
