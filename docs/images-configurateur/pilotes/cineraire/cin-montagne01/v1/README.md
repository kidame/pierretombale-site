# CIN-MONTAGNE01 - pilote v1

Source : libfile_2a316d6ce1388191b2a548a52e7cee86.
Dalle rectangulaire simple, stele haute a silhouette de chaine montagneuse: grand sommet a gauche, sommet intermediaire puis sommet bas a droite. Bords epais irreguliers a aspect eclate. Le paysage blanc frontal est traite comme gravure optionnelle. La silhouette montagneuse et les chants eclates restent. Les chants clairs sont interpretes comme finition brute de la meme pierre, pas comme incrustation. Geometrie atelier et zones physiques a valider.

Une vue par matiere ; nom public et calibration non valides.
