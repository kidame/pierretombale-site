# CIN8 - pilote v1

Source : libfile_24ecdbef74388191947ef8fc207743c0.
Dalle de base presque carree, stele massive en coeur a deux lobes, pointe basse descendant jusqu'a un pied elargi aux deux courbes concaves. Bande/ressaut fixe en S sur la dalle, de l'arriere gauche vers l'avant droit. Retirer vase, roses, feuillage et leurs reflets. Conserver le coeur complet, son pied evase et la bande structurelle en S sur la dalle. Toutes les parties minerales du monument varient ensemble.

Une vue par matiere ; nom public et calibration non valides.
