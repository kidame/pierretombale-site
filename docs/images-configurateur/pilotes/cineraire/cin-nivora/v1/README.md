# CIN-NIVORA - pilote v1

Source : libfile_555f2952e5208191bd8b2c71e1434091.
Deux dalles rectangulaires superposees avec semelle debordante, marche transversale arriere. Grande stele circulaire en acier ajoure dessine un arbre avec racines, branches et feuilles. Petit coeur epais en granit devant a gauche. Arbre en acier ajoure conserve entierement, sans changement de matiere. Le petit coeur separe est conserve par prudence comme composant du modele; sa fixation n'est pas visible. Seules les pieces en pierre varient. Geometrie atelier et zones physiques a valider.

Une vue par matiere ; nom public et calibration non valides.
