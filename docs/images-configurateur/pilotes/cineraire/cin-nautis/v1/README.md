# CIN-NAUTIS - pilote v1

Source : libfile_69f17f5e19148191b2577f26c8062005.
Semelle rectangulaire, deux niveaux courbes superposes en forme de vagues. Stele sculptee en voilier: coque incurvee basse et deux surfaces de voile effilees separant une ligne de mat courbe. Galet clair pose a gauche. Bicolore conserve : base et vagues varient; voilier clair veine reste fixe. Le galet clair separe est traite comme accessoire pose, fixation non visible. Coque, voiles et leurs limites sont structurelles. Geometrie atelier et zones physiques a valider.

Une vue par matiere ; nom public et calibration non valides.
