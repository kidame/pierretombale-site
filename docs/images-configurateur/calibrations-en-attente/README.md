# Calibrations en attente

Fichiers de calibration traces mais NON publies : le configurateur ne lit que
`src/data/calibrations/`. Pour publier un modele, deplacer son fichier la-bas
(et rebuild). Chaque fichier garde ses coordonnees en px source 1254.

- tango.json (23.10.2026) : vue de 3/4, deux steles cintrees. Zone posee sur la
  face polie de la grande stele (34 cm) : trop etroite, le texte par defaut
  deborde des la premiere ligne. A reprendre avec une vue de face, ou en
  choisissant la petite stele (51 cm) apres avis de Thomas.
